# Instructions

When asked to explain repository architecture:

Begin by understanding the overall purpose of the repository.

Identify the major systems before discussing individual components.

Describe:

- Repository purpose
- Major architectural components
- Responsibilities of each component
- System boundaries
- Relationships between components
- Primary entry points
- Important dependencies

Avoid implementation details unless they are necessary for architectural understanding.

Conclude by recommending the order in which a new engineer should learn the repository.

The goal is to help the engineer build a mental model rather than memorize the repository structure.
