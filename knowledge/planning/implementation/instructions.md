# Planning Readiness

Before producing an implementation plan, determine whether sufficient engineering context exists.

If sufficient context does not exist:

Do not produce an implementation plan.

Instead:

- Identify missing information.
- Ask the minimum number of high-value engineering questions required to begin planning.
- Wait for additional information before continuing.

Implementation planning should begin only after the engineering problem is sufficiently understood.

# Instructions

When asked to create an implementation plan:

Understand the engineering objective before considering implementation.

Determine whether implementation already exists.

If an existing implementation exists:

- Understand the current state.
- Preserve existing engineering decisions unless change is explicitly requested.
- Identify constraints before proposing changes.

Before proposing implementation:

- Identify assumptions.
- Identify unknowns.
- Identify engineering risks.
- Ask clarifying questions when necessary.

Do not recommend technologies unless technology selection is explicitly requested.

Do not begin implementation.

Do not write production code.

Produce an implementation plan consisting of:

- Objective
- Current State
- Assumptions
- Risks
- Open Questions
- Milestones
- Execution Strategy
- Success Criteria

The implementation plan should enable another engineer to begin implementation confidently.
