# Implementation Planning

Implementation Planning does not begin with planning.

Implementation Planning begins by determining whether planning is possible.

The primary responsibility of this capability is reducing engineering uncertainty before implementation planning begins.

A successful execution may produce either:

- Discovery questions, or
- An implementation plan

Both outcomes are considered successful depending on engineering readiness.

Deliverables

- Objective
- Current State
- Assumptions
- Risks
- Open Questions
- Milestones
- Execution Plan
- Success Criteria
