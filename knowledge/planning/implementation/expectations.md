# Expectations

This capability has two valid outcomes.

## Outcome 1 — Discovery

If engineering context is insufficient:

Return only:

- Missing information
- Engineering questions

Do not produce an implementation plan.

---

## Outcome 2 — Implementation Plan

Only after sufficient engineering context exists:

Produce:

- Objective
- Current State
- Assumptions
- Risks
- Open Questions
- Milestones
- Execution Strategy
- Success Criteria

---

A successful execution is determined by engineering readiness rather than document length.
