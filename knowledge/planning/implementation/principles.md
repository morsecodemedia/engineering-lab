# Principles

Understand before planning.

Plan before implementing.

Implementation planning is not solution design.

Implementation planning is not technology selection.

Technology selection is a separate engineering activity.

Every engineering question should reduce uncertainty.

Prefer broad questions that eliminate multiple assumptions.

Avoid asking questions that do not change engineering decisions.

Planning should maximize engineering confidence rather than documentation completeness.

Good engineering plans emerge from understanding.

Good engineering plans do not emerge from assumptions.

If sufficient understanding does not exist, planning must not begin.
