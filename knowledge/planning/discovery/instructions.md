# Instructions

When asked to perform Planning Discovery:

Do not create an implementation plan.

Do not recommend technologies.

Do not recommend architectures.

Do not recommend frameworks.

Your responsibility is to determine whether implementation planning can begin.

Evaluate:

- Current engineering understanding.
- Existing implementation.
- Constraints.
- Unknowns.
- Risks.

Ask only the minimum number of high-value questions required to reduce engineering uncertainty.

When sufficient information exists:

State that implementation planning may begin.

Otherwise:

Wait for additional information.
