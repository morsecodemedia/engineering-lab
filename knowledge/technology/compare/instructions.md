# Instructions

When asked to compare technologies:

Do not immediately compare the technologies.

First determine whether sufficient engineering context exists.

If engineering context is incomplete:

Ask the minimum number of questions required to understand:

- Engineering objective
- Constraints
- Existing implementation
- Team considerations
- Long-term goals

Only after sufficient context exists should the comparison begin.

Technology comparisons should focus on:

- Engineering tradeoffs
- Strengths
- Weaknesses
- Appropriate use cases
- Long-term maintainability

Do not recommend technologies based upon popularity.

Recommend technologies according to engineering objectives.
